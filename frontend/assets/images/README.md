# Asset Images for TimeCapsule App

This folder contains images for the app. You can download free images from:
- Unsplash: https://unsplash.com
- Pexels: https://pexels.com

## Required Images:

1. **profile_placeholder.png** - Default profile picture (circular avatar)
   - Suggested: Abstract/gradient circular pattern
   - Size: 512x512px
   - Source: https://unsplash.com/photos/person-icon

2. **sent_empty.png** - Empty state for sent capsules
   - Suggested: Time capsule, gift box, or send icon illustration
   - Size: 400x400px
   - Source: https://unsplash.com/s/photos/gift-box

3. **received_empty.png** - Empty state for received capsules
   - Suggested: Mailbox, inbox, or receive illustration
   - Size: 400x400px
   - Source: https://unsplash.com/s/photos/mailbox

4. **statistics_bg.png** - Background for statistics cards
   - Suggested: Abstract gradient or pattern
   - Size: 800x600px
   - Source: https://unsplash.com/s/photos/abstract-gradient

5. **capsule_locked.png** - Icon for locked capsules
   - Suggested: Lock or time-locked concept
   - Size: 256x256px
   - Source: https://unsplash.com/s/photos/lock

6. **capsule_unlocked.png** - Icon for unlocked capsules
   - Suggested: Open lock or unlocked concept
   - Size: 256x256px
   - Source: https://unsplash.com/s/photos/unlock
